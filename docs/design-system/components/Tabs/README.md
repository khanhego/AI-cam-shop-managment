# Tabs

Tab chính theo M3: chỉ báo 3px màu `primary` dưới tab đang chọn. Thanh tab tự cuộn ngang khi hẹp.

**Props**: `items` (danh sách `[key, nhãn]`), `value`, `onChange`, `label` (`aria-label` của tablist).

Dùng để chia các khung nội dung của cùng một đối tượng, ví dụ Segments / Transcript / Dữ liệu thô. Không dùng thay cho điều hướng trang. Tab admin là link, dùng cùng chỉ báo.
