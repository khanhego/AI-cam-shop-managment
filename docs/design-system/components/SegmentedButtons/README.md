# SegmentedButtons

Nhóm nút chọn một, cao 40px, viền `outline`. Mục đang chọn có nền `secondary-container` và icon `check`.

**Props**: `options` (danh sách `[key, nhãn, icon?]`, từ 2 đến 5 mục), `value`, `onChange`, `label` (bắt buộc, `aria-label` của group). Mỗi nút có `aria-pressed`.

Dùng để chọn chế độ xem (Danh sách / Nhóm) hoặc khoảng thời gian.
