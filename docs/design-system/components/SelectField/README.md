# SelectField

Ô chọn outlined dùng cùng khung với TextField, có mũi tên vẽ bằng CSS.

**Props**: giống TextField; con là các `<option>`.

**Quy tắc**: option đầu tiên dạng "— Chọn gian hàng —" có `value=""`. Khi select phụ thuộc vào một select khác thì set `disabled` và ghi hint "Chọn gian hàng trước".
