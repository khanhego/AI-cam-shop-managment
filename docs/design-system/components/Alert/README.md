# Alert

Banner trong trang hoặc form. Tone `error` dùng `role="alert"`, các tone khác dùng `role="status"`.

**Props**: `kind` (`error`, `success`, `info`, `warning`), `children`, `action` (thường là một Button `text` hoặc `tonal`).

**Quy tắc**: nội dung nói rõ chuyện gì xảy ra và cần làm gì tiếp, kèm mã lỗi khi hữu ích cho hỗ trợ. Mỗi vùng có tối đa một Alert lỗi.
