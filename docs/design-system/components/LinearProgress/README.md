# LinearProgress

Thanh tiến độ xác định, cao 4px, rãnh màu `surface-container-highest`.

**Props**: `value` (0–100), `label` (bắt buộc, làm `aria-label`), `tone` (`primary` hoặc `error`).

Dùng cho hạn mức tháng, upload và từng bước pipeline. Luôn hiện số liệu dạng chữ bên cạnh, ví dụ "9/100 video".
