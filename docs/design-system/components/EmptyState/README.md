# EmptyState

Trạng thái rỗng, đặt trong card: icon tròn trên nền `secondary-container`, tiêu đề `title-md`, một câu giải thích và **một** hành động.

**Props**: `icon`, `title`, `children` (giải thích), `action`.

Có 2 loại:
- Chưa có dữ liệu: action dẫn tới bước tạo, ví dụ "Kết nối shop".
- Lọc không ra kết quả: action là nút "Xoá bộ lọc" kiểu `tonal`.
